# پلک (pelc)

**استودیوی طراحی خوشنویسی فارسی و عربی — اندروید بومی، فارسی‌محور، کاملاً آفلاین**

<div dir="rtl">

پلک یک اپ اندروید بومی (Kotlin + Jetpack Compose + Material 3) برای طراحی خوشنویسی است: از ثلث و نسخ تا کوفی، رقعه و نستعلیق. حروف با HarfBuzz واقعاً شکل می‌گیرند (اتصال درست، جای‌گذاری اِعراب)، هر حرف می‌تواند قلم و «گونه» (variant) مستقل داشته باشد، و خروجی در همهٔ قالب‌های حرفه‌ای — PSD لایه‌باز، PNG، JPG، SVG، PDF، DXF — بدون هیچ واترمارکی گرفته می‌شود.

</div>

## ویژگی‌ها

- **شکل‌دهی واقعی فارسی/عربی** با HarfBuzz روی NDK — خروجی وکتوری مستقل از فونت نصب‌شدهٔ دستگاه
- **ویرایش سه‌سطحی:** لایه / واژه / حرف
- **گونه‌های حرف** (ss01..ss20، salt، cv، swsh، …) — فقط گونه‌هایی که واقعاً شکل حرف را عوض می‌کنند پیشنهاد می‌شوند و در بستر واقعی واژه اعمال می‌شوند
- **قلم-به-حرف:** هر حرف می‌تواند فونت متفاوتی داشته باشد
- **خروجی حرفه‌ای:** PSD لایه‌باز (نام لایه‌های فارسی)، PNG شفاف، JPG (کیفیت/پس‌زمینه)، SVG وکتوری، PDF وکتوری، DXF برای لحیه‌سازی
- **فلو ذخیرهٔ درست:** روی ذخیره، قالب از کاربر پرسیده می‌شود؛ سند همیشه به‌صورت `.pelc` هم ذخیره می‌شود
- **واگرد/ازنو تا ۵۰۰ گام** + تاریخچهٔ بی‌درسر هنگام کشیدن لایه
- **رابط کاملاً فارسی و RTL** با تم مرکبی/طلایی
- **آفلاین و خصوصی:** بدون کلید API، بدون تبلیغ؛ ورود قلم شخصی با SAF

## ساخت سریع

```bash
git clone https://github.com/<USER>/pelc && cd pelc
./scripts/fetch-fonts.sh          # فونت‌های OFL (اختیاری؛ ورود قلم از داخل اپ هم ممکن است)
./gradlew :app:assembleDebug      # APK → app/build/outputs/apk/debug/app-debug.apk
```

پیش‌نیازها: JDK 17، Android SDK 35، NDK 27.0.12077973، CMake 3.22.1 (بار اول HarfBuzz به‌صورت خودکار دانلود می‌شود؛ برای بیلد آفلاین `./scripts/fetch-native-deps.sh`).

تست‌ها:

```bash
./gradlew :core-model:test :core-export:testDebugUnitTest
```

## ساختار مخزن

```
pelc/
├── app/                  # اکتیویتی، تم، DI، manifest، منابع فارسی
├── core-model/           # مدل سند نسخه‌دار + سریال‌سازی JSON (+تست)
├── core-shaping/         # HarfBuzz JNI + CMake + چیدمان RTL + آشکارساز گونه‌ها
├── core-render/          # موتور رندر + کش مسیر گلیف
├── core-export/          # PNG/JPG/SVG/PDF/DXF/PSD/.pelc (+تست‌های JVM)
├── feature-editor/       # ویرایشگر Compose: لایه/واژه/حرف + undo/redo
├── feature-export/       # برگزینندهٔ قالب + WorkManager Worker
├── feature-fonts/        # مخزن قلم + ورود قلم SAF
├── docs/                 # معماری، نقشهٔ راه، مجوزها، راهنمای آپلود
├── scripts/              # fetch-fonts.sh · fetch-native-deps.sh
└── .github/workflows/    # CI (تست+APK) و Release (APK+AAB)
```

## فونت‌ها و مجوزها

فونت‌های همراه همگی **SIL OFL 1.1** هستند (فهرست کامل در [`docs/FONT_LICENSES.md`](docs/FONT_LICENSES.md)). سبک‌های **ثلث** و **دیوانی** فونت آزادِ بازتوزیع‌پذیر ندارند؛ برای آن‌ها از «قلم تازه» فایل خودتان را وارد کنید.

## مشارکت

### شروع سریع در اپ

۱) اپ را باز کنید → «افزودن متن» → مثلاً «بسم الله الرحمن الرحیم» بنویسید.
۲) در تب «واژه» قلم را عوض کنید؛ در تب «حرف» یک حرف را انتخاب و یکی از گونه‌ها را بزنید.
۳) دکمهٔ ذخیره → قالب خروجی را انتخاب کنید؛ فایل و یک `.pelc` کنارش ساخته می‌شود.
