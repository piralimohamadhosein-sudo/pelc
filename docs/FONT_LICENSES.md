# مجوز فونت‌ها — مفروضه‌های صریح

## فونت‌های همراه (Bundled)

همهٔ فونت‌هایی که خودمان بسته می‌کنیم باید **مجوز آزاد و بازتوزیع‌پذیر** داشته باشند. انتخاب فعلی: همه **SIL OFL 1.1** از مخزن رسمی Google Fonts:

| فونت | سبک | مجوز | منبع |
|---|---|---|---|
| Amiri (Regular/Bold) | نسخ | OFL 1.1 | `google/fonts → ofl/amiri` |
| Scheherazade New | نسخ | OFL 1.1 | `ofl/scheherazadenew` |
| Reem Kufi | کوفی | OFL 1.1 | `ofl/reemkufi` |
| Aref Ruqaa (Regular/Bold) | رقعه | OFL 1.1 | `ofl/arefruqaa` |
| Lateef | نسخ | OFL 1.1 | `ofl/lateef` |
| Gulzar | نستعلیق | OFL 1.1 | `ofl/gulzar` |
| Noto Nastaliq Urdu | نستعلیق | OFL 1.1 | `ofl/notonastaliqurdu` |
| Noto Naskh Arabic | نسخ | OFL 1.1 | `ofl/notonaskharabic` |
| Noto Kufi Arabic | کوفی | OFL 1.1 | `ofl/notokufiarabic` |
| Harmattan | نسخ | OFL 1.1 | `ofl/harmattan` |

الزام: فایل `.ttf/.otf` وارد مخزن نمی‌شود؛ `scripts/fetch-fonts.sh` در زمان بیلد دانلود می‌کند تا مجوز بازتوزیع هر نسخه با منبع اصلی هم‌راستا بماند.

## سبک‌هایی که فونت آزاد ندارند (مفروضهٔ مهم)

- **ثلث:** هیچ فونت ثلث باکیفیتی با مجوز باز بازتوزیع شناخته‌شده وجود ندارد؛ فونت‌های موجود تجاری‌اند. → کاربر فایل فونت را با SAF وارد می‌کند (و تأیید می‌کند مجوزش را دارد). پشتیبانی ورود قلم از فاز ۱ فعال است.
- **دیوانی:** وضعیت مشابه ثلث.
- برای این دو سبک، دکمهٔ «قلم تازه» در تب «واژه» مسیر اصلی است.

## قلم واردشده توسط کاربر

- فقط در فضای خصوصی برنامه ذخیره می‌شود؛ **در هیچ `.pelc` یا خروجی‌ای جاسازی نمی‌شود مگر اینکه خود کاربر ذخیره کند** (الزام جاسازی فونت در `.pelc` برای حفظ سند قابل‌ویرایش).
- برنامه هرگز مجوز قلم‌های تجاری را جایگزین نمی‌کند؛ مسئولیت رعایت مجوز با کاربر است.
